# Underdog战队 - CRTC2026 机器人开发主日志

## 项目概述
本仓库记录了Underdog战队参加重庆大学机器人训练大赛（CRTC2026）的完整开发历程。本次比赛我们的机器人为一台具备高机动性、能够进行资源（能量单元/核心）收集与占有的半自动机器人。

## 开发时间线规划
- **9月10日 - 9月20日**：需求分析，方案论证，完成初步采购单。
- **9月21日 - 10月10日**：机械结构初版设计与3D打印，底盘搭建。
- **10月11日 - 10月18日**：电控系统调试，基础功能实现，完成中期考核视频录制。
- **10月19日 - 10月24日**：机器人迭代优化，进阶功能（视觉辅助）开发，准备瑞士轮比赛。

## 开源项目说明
本队伍在机器人制作及代码编写过程中，严格遵守开源协议。
1. **FreeRTOS内核**：使用官方开源版本进行任务调度。
2. **麦轮运动学解算**：参考了GitHub开源项目 `Mecanum-Wheel-Kinematics`（MIT协议），并在其基础上针对我们的底盘参数进行了修改。
3. **PS2手柄库**：使用了开源库 `PS2X_lib`（Apache-2.0协议），用于SPI通讯解析。
所有引用的开源代码及协议均已在对应的技术日志中详细标注。
