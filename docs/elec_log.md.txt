2. 电机驱动（PWM + 小电机）
2.1 目标
让小车 4 个轮子能独立调速转动（电机运动（单一）、电机运动（全部））。
2.2 选型
主控为 STM32F103C8T6：物资表指定且培训与教程资料最多。
驱动模块为 DRV8833：对比 DRV8833 / TB6612FNG / L298N。DRV8833 体积小、双路 H
桥（一片带两路电机，2 片即可驱动 4 轮），3.3V 逻辑电平与 STM32 兼容、接线简单；
L298N 体积大且需额外逻辑电源；TB6612FNG 性能相近但成本略高。
调速方式为 PWM：通过定时器输出 PWM 控制占空比实现调速。
2.3 进度
10.10–10.14：学习直流电机调速原理（PWM 占空比决定平均电压，进而决定转速）、TT 马
达与舵机的区别、H 桥驱动原理（DRV8833 内部为双路 H 桥）、定时器 PWM 配置
（72MHz 时钟下 10000Hz 对应预分频 72、自动重装载值 100，每路电机需两路 PWM：
调速 + 方向）、堵转电流问题与驱动模块的必要性。
10.15–10.19（方案验证）：DRV8833 / TB6612FNG / L298N 三种驱动模块的对比，最终确定
DRV8833；绘制了主控 →DRV8833 →电机的接线规划（每组 PWM + 方向各占 2 个
GPIO）；确定了 PWM 频率选择依据（高频可减小电机啸叫与抖动）。
10.18 起初用主控引脚直接驱动电机，没有反应，后来才加上驱动模块，因为引脚电流远不足
以带动电机启动与堵转电流；加上驱动模块后成功驱动带底座和小扇叶的直流电机，通过
STM32 输出 PWM 控制其转动与调速，验证了 GPIO 与定时器 PWM 通路。
3. 底盘运动控制（PS2 手柄 + 麦克纳姆轮）
3.1 目标
让小车被手柄控制，实现前进、后退、横移、原地转圈（底盘运动（单一）、底盘运动（全
部））。
3.2 选型
遥控方式选 PS2 手柄：物资表指定，支持对频锁定避免串台；培训文档提供了单指示灯 / 双
指示灯两种配置教程与现成驱动代码（ps2.h/c、ax_ps2.h/c）。
底盘用麦克纳姆轮：通过 4 轮转速组合实现全向移动（横移、斜行、原地转），抢方块灵
活；比赛场地为 6mm 白色地胶，平整度高，麦轮性能可以发挥。
运动：采用经典麦轮逆运动学公式，将手柄摇杆的纵向 / 横向 / 旋转速度映射为 4 轮转速，
先用推导验证公式符号，再上机实测。
3.3 进度
10.5–10.10：SPI 同步全双工主从协议（SCLK/MOSI/MISO/CS 信号、CPOL/CPHA 四种模
式、片选时序、DMA 传输注意事项）、PS2 手柄数据帧结构、PS2 手柄读取配置（SPI1 接
口、PA4 作为 ENABLE、导入 ps2.h/c 到工程）、麦轮运动学解算（逆运动学公式将摇杆速
度映射为 4 轮转速）。
10.15–10.19：完成麦轮逆运动学公式推导与符号约定，用表格代入多组输入（前进、横移、
原地转）核对 4 轮转速的方向符号；梳理了 SPI 读取流程（初始化 →拉低 CS →读取数据
→释放 CS）。电机驱动跑通后，验证 SPI 能否稳定读取摇杆数据（用串口打印；摇杆数据
做死区处理与映射，联动 4 轮运动学输出
4. 舵机机构控制（SG90 夹爪）
4.1 目标
用舵机带动夹爪开合，完成方块夹取与释放 (舵机运动（单一）、方块携带（单一）)
4.2 选型
舵机选 SG90（普通版）：以 SG90 通过 PWM 控制角度。控制方式为 50Hz PWM
（72MHz 时钟下预分频 720、自动重装载值 2000），脉宽对应角度；接线：红线 5V、棕
线 GND、黄线信号。普通 SG90 支持 0°–180° 定位；360° 连续旋转版只能连续转、不能
定位角度，故本队选用普通版。
4.3 进度
10.10–10.14：舵机工作原理（PWM 脉宽对应角度）、普通 SG90（0°–180° 定位）与 360°
连续旋转版的区别、50Hz PWM 配置（72MHz 时钟下预分频 720、自动重装载值 2000）、
夹爪机构原理（连杆开合）。
10.15-10.18：绘制舵机角度 - 脉宽对照表（0°/90°/180° 对应脉宽计算）；根据方块
30×30×30mm 的尺寸讨论夹爪开口行程与留量。
10.18–10.19：用 STM32 输出 50Hz PWM 实测 SG90 转动，0°/90° 位置可以稳定复现，
与理论脉宽对照表印证
4.4 计划
补齐 180° 与夹爪所需角度的精确标定；与机械组配合设计简单夹爪，完成开合测试；装车后
联调 "夹取 - 携带 - 释放"
5. 电源
5.1 目标
为整车提供稳定供电并满足检录安全要求（无线继电器 10m 遥控断电）。
5.2 选型
电池选 18650 两节串联：额定 7.4V，刚好符合规则 "单供电模块 ≤7.4V" 上限，兼顾电机电
压需求；官方物资表指定 18650。
降压方案：主控 / 逻辑需要 5V/3.3V，采用 DC-DC 降压模块从 7.4V 降压，效率高于线性
降压、发热小。
无线断电继电器：要求 10m 范围内可遥控断电；接线串联在电池总正极，实现整车硬断电。
5.3 进度
10.4–10.5：学习 18650 电池特性（两节串联额定 7.4V）、DC-DC 降压原理（7.4V →
5V/3.3V）、无线继电器断电链路。
10.18–10.19：完成供电拓扑设计（电池 →总开关 / 无线继电器 →电机驱动 / DC-DC 降压
→主控），核算各模块电压等级，确定无线继电器串联在电池总正极实现整车硬断电
